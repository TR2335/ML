## 写计划阶段的裁定（Plan Rulings）

1. **R-P8-1 — 契约补第 6 字段 `ed_visits_6m`**：主 WBS T8.1 与设计文档 §5 只列 5 字段，但 T8.3 要求 LACE 基线，LACE 的 E 维度（近 6 个月急诊次数）无字段可用——补 `ed_visits_6m: int(0..100)`，同步更新 §5 与 data-contract。成本若错：多一个必填字段，真实数据抽取多取一列。
2. **R-P8-2 — 出院快照挂 discharge 事件 `payload`**：`PatientRecord` 不动；校验放 `app/domain.py` 的 `ClinicalEvent` 模型校验器，API（422）与导入（ValidationError）自动共用同一条字段级错误。成本若错：无，WBS"出院记录被拒并给出字段级错误"两条路径都覆盖。
3. **R-P8-3 — readmission 特征空间 = 6 维编码**：`[los_days, prior_utilization_12m, comorbidity_index, ed_visits_6m, diagnosis_code_count, discharge_destination_code]`；`discharge_destination ∈ {home, home_health, snf, other}` 映射序数 0–3（枚举由 T8.1 校验钉死）；`diagnosis_code_count = len(diagnosis_codes)`。编码器 `app/features.py::encode_readmission_payload` 训练/serving 共用；serving 端对派生名（`diagnosis_code_count`/`discharge_destination_code`）按 payload 即时计算（沿用 P6 R2 的 `__missing` 模式）。成本若错：序数编码把分类当有序——demo 可接受，真实数据可换 one-hot。
4. **R-P8-4 — 触发策略与批路径语义**：`targets_for_event(event)` 放 `app/domain.py`（纯函数，返回 `TargetId` 列表）；`rescore_once`/`reconcile` 对 readmission 只在该就诊**存在出院事件**时补算/保鲜，as_of 基准 = **首个出院事件时刻**（后续生命体征不刷新再入院分数；`upsert_score` 的 as_of 防倒退天然兜底）。成本若错：无出院事件的就诊永远没有再入院分数——这正是"出院触发"语义。
5. **R-P8-5 — LACE 分值表**（Austin 2010，总分 0–19）：L 住院天数 ≤1/2–3/4–6/≥7 → 0/1/2/3；A 近12月入院 0/1/2/≥3 → 0/2/4/7；C Charlson 0/1/2–3/≥4 → 0/2/4/6；E 近6月急诊 0/1/2/≥3 → 0/1/2/3。**本环境网络受限未能在线核对原文**——表以常量落库并注释声明，合并前人工对照 Austin et al.. CMAJ 2010 复核；测试手算钉住的是本表（自洽）。成本若错：demo 基线数值偏移，门禁机制（模型 vs 基线的相对比较）不受影响。
6. **R-P8-6 — 门禁基线按目标分派**：`run_promotion_gate` 中 deterioration→news2（P6 既有），readmission→LACE（行内 `los_days/prior_utilization_12m/comorbidity_index/ed_visits_6m` 现算）；CI-lo ≥ 基线 AUPRC 且 ECE<0.05 公式不变。成本若错：无。
7. **R-P8-7 — 统一 `payload_from_row`**：`scripts/evaluate_model.py` 新增共享函数（跳过 meta 列、空值跳过、NaN 跳过、`diagnosis_codes` JSON 解析、其余尝试 float），`evaluate_rows`/`active_label`/golden 测试构造器共用——golden/阈值/门禁/标注四条 CSV 路径对双目标一致。成本若错：非数值字符串列进入 payload（引擎按 feature_order 取用，未知键无害）。
8. **R-P8-8 — readmission demo 标签改为字段驱动**：合成出院字段（确定性种子）先生成，再入院结局概率 = sigmoid(字段线性组合)，正例率仍 ≈8%——否则逻辑回归学不到信号、无法在门禁中打赢 LACE。阈值改为**双目标都从各自 demo_dataset 反推**（P6"异分布"的不反推理由随特征空间统一而消失）。成本若错：demo 标签不再走固定 8% 均匀抽样，但派生管道与结局机制（`derive_labels`+horizon）不变。

```python
DISCHARGE_DESTINATIONS = ("home", "home_health", "snf", "other")
DISCHARGE_SNAPSHOT_FIELDS = (

    "diagnosis_codes",
    "comorbidity_index",
    "prior_utilization_12m",

    "los_days": (0.0, 365.0),
    "comorbidity_index": (0.0, 40.0),
    "prior_utilization_12m": (0, 100),
    "ed_visits_6m": (0, 100),
}
```

`ClinicalEvent` 类内（`validate_payload` 之后）：

```python
    @model_validator(mode="after")
    def validate_discharge_snapshot(self) -> "ClinicalEvent":
        if self.event_type != "discharge":
            return self
        missing = [name for name in DISCHARGE_SNAPSHOT_FIELDS if name not in self.payload]
        if missing:
            raise ValueError("discharge payload missing fields: " + ", ".join(missing))
        destination = self.payload["discharge_destination"]
        if not isinstance(destination, str) or destination not in DISCHARGE_DESTINATIONS:
            raise ValueError(
                f"discharge_destination must be one of {', '.join(DISCHARGE_DESTINATIONS)}"
            )
        codes = self.payload["diagnosis_codes"]
        if (
            not isinstance(codes, list)
            or len(codes) > 50
            or not all(isinstance(code, str) and 0 < len(code) <= 16 for code in codes)
        ):
            raise ValueError("diagnosis_codes must be a list of up to 50 short strings")
        for name, (minimum, maximum) in DISCHARGE_NUMERIC_RANGES.items():
            value = self.payload[name]
            if isinstance(value, bool):
                raise ValueError(f"{name} must be numeric")
            try:
                numeric = float(value)
            except (TypeError, ValueError) as exc:
                raise ValueError(f"{name} must be numeric") from exc
            if not math.isfinite(numeric) or not minimum <= numeric <= maximum:
                raise ValueError(f"{name} must be between {minimum} and {maximum}")
        return self
```

```python
def reconcile(store: Store, engines: dict[TargetId, RiskEngine]) -> int:
    """Backfill missing or stale scores from durable events without regressing newer ones.

    readmission_30d 以首个出院事件为基准（WBS T8.2）：无出院事件则不要求该分数。
    """
    count = 0
    for tenant_id, facility_id, encounter_id, latest in store.encounter_latest_event_times():
        scores = store.get_scores(encounter_id, tenant_id, facility_id)
        events = store.events_for(encounter_id, tenant_id, facility_id)
        if not events:
            continue
        discharge = _first_discharge(events)
        plans: list[tuple[TargetId, RiskEngine, datetime, ClinicalEvent | None]] = []
        if "deterioration_24h" in engines:
            current = scores.get("deterioration_24h")
            if current is None or (current.as_of or current.scored_at) < latest:
                plans.append(("deterioration_24h", engines["deterioration_24h"], latest, None))
        if "readmission_30d" in engines and discharge is not None:
            current = scores.get("readmission_30d")
            if current is None or (current.as_of or current.scored_at) < discharge.occurred_at:
                plans.append(
                    ("readmission_30d", engines["readmission_30d"], discharge.occurred_at, discharge)
                )
        if not plans:
            continue
        latest_event = max(events, key=lambda event: event.occurred_at)
        for _target_id, target_engine, as_of, trigger in plans:
            snapshot = store.feature_snapshot(encounter_id, tenant_id, facility_id, as_of=as_of)
            source = trigger or latest_event
            scoring_event = source.model_copy(update={"payload": snapshot})
            store.upsert_score(target_engine.score(scoring_event))
        count += 1
    return count
```

```python
# LACE 分值表（Austin et al., CMAJ 2010；Ruling R-P8-5：离线环境未能在线核对原文，
# 合并前请对照原文复核分箱边界）。总分 0–19。


def lace_score(row: Mapping[str, Any]) -> int:
    """Return the LACE readmission-risk index (0-19) for a discharge snapshot row."""
    required = ("los_days", "prior_utilization_12m", "comorbidity_index", "ed_visits_6m")
    values: dict[str, float] = {}
    for name in required:
        if name not in row or row[name] in ("", None):
            raise ValueError(f"lace fields missing/invalid: {name}")
        try:
            numeric = float(row[name])
        except (TypeError, ValueError) as exc:
            raise ValueError(f"lace fields missing/invalid: {name}") from exc
        if not math.isfinite(numeric):
            raise ValueError(f"lace fields missing/invalid: {name}")
        values[name] = numeric

    los = values["los_days"]
    length = 0 if los <= 1 else 1 if los <= 3 else 2 if los <= 6 else 3
    admissions = values["prior_utilization_12m"]
    admission = 0 if admissions < 1 else 2 if admissions < 2 else 4 if admissions < 3 else 7
    charlson = values["comorbidity_index"]
    comorbidity = 0 if charlson < 1 else 2 if charlson < 2 else 4 if charlson < 4 else 6
    visits = values["ed_visits_6m"]
    emergency = 0 if visits < 1 else 1 if visits < 2 else 2 if visits < 3 else 3
    return length + admission + comorbidity + emergency
```

```python
def encode_readmission_payload(payload: Mapping) -> list[float]:
    """出院快照 → 6 维再入院特征（训练/serving 唯一编码源，Ruling R-P8-3）。

    源字段缺失填 NaN（与 P6 中位数填补语义一致）。
    """

    def _number(name: str) -> float:
        raw = payload.get(name)
        if raw in ("", None):
            return math.nan
        try:
            value = float(raw)
        except (TypeError, ValueError):
            return math.nan
        return value if math.isfinite(value) else math.nan

    codes = payload.get("diagnosis_codes")
    if isinstance(codes, str) and codes.strip():
```
