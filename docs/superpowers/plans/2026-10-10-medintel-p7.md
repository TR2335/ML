## 写计划阶段的裁定（Plan Rulings）

1. **R-P7-1 — `--algorithm` 默认 `logistic`**：WBS 说"新增 `--algorithm lightgbm` 分支"未言默认切换；保持 logistic 默认 → golden fixtures 不换代、CI `--check` 不受本计划影响；LightGBM 为显式挑战者。成本若错：无。
2. **R-P7-2 — 单调约束向量**：按 `app/risk.py::DEFAULT_WEIGHTS` 符号 + 临床方向生成（deterioration 21 维序）：`age=+1, heart_rate=+1, respiratory_rate=+1, systolic_bp=-1, temperature=+1, spo2=-1, wbc=+1, creatinine=+1, lactate=+1, prior_admissions_30d=+1`，10 个 `__missing` 指示列 `0`（不约束），`news2_score=+1`；readmission 6 维 = `[1,1,1,1,1,0]`（`discharge_destination_code` 序数不约束）。temperature 取 +1（工件线性权重 +0.55 的方向；|t-37| 的 U 形属 else-分支旧行为，v2 工件未用）。成本若错：约束方向与临床共识偏差时模型单调性错向——以 DEFAULT_WEIGHTS 符号为准可审计。
3. **R-P7-3 — 树工件形状**：`algorithm: "lightgbm"`；`trees: [{nodes: [{feature_order_index, threshold, left, right, value, default_left}], shrinkage}]`（叶子 value 为累加分数；`feature_order_index` 指向 `feature_order`；`default_left` 记录 LightGBM 缺失走向）；另携 `booster_text`（`Booster.model_to_string()`，走分对照真值与恢复）；`weights` = 全 0 占位、`bias` = 0（保持 `_load` 契约），`preprocess = None`，`calibration` 走既有链。走分：nan/缺失按 `default_left` 下钻；叶子和×shrinkage → 加 bias →（校准）→ sigmoid。成本若错：无，形状自描述且有测试钉住。
4. **R-P7-4 — Optuna 可注入**：`--trials`（默认 100）、`--seed`（默认 20261010，`TPESampler(seed)` 确定性）；目标 = 时间 CV 平均 AUPRC − 0.1×ECE（WBS 原文）；测试用 `--trials 2` 保速；单类训练折跳过（沿 P6 口径）。成本若错：无。
5. **R-P7-5 — isotonic 默认 + Platt 兼容**：`train_model` 校准段拟合 `IsotonicRegression(out_of_bounds="clip")`，工件 `calibration: {method:"isotonic", x_thresholds:[...], y_scores:[...], fitted_on}`（x 严格升序、y 非降）；`RiskEngine._load` 解析双 method（platt 既有解析不动，未知 method → ValueError），`_score`/`_score_tree` 在 sigmoid 前统一 `_isotonic_apply`（分段线性插值、端点 clip，纯 Python）。P6 测试 `method=="platt"` 断言更新为 isotonic。fixtures 任务内重冻结。成本若错：无。
6. **R-P7-6 — 门禁新规则按数据可用性降级**：亚组（需 `age` 列且两组各 ≥10 阳性）、院区（需 `facility_id` 列且 ≥2 院区、每合格院区 ≥20 行且 ≥5 阳性）、决策曲线（恒可算）——前置不满足则该规则 **`status:"skipped"` 注明原因、不判失败**；只有 `status=="fail"` 才压低 `passed`。既有 16 行 gate fixture 无 age/facility → 亚组/院区跳过，语义不变。成本若错：前置过宽会让规则形同虚设——数值门槛与逐规则报告可审计。
7. **R-P7-7 — "留一院区验证"落地口径**：promote 门禁内做**按院区划分评估**（每个合格院区 AUPRC ≥ 基线点估计）；真正"训练时留一院区重训"需多次训练，属真实数据阶段。成本若错：门禁强度弱于字面——报告逐院区数字留痕。
8. **R-P7-8 — 决策曲线规则**：阈值网格 0.10–0.90 步长 0.05；`mean(NB_model − max(NB_treat_all, 0)) ≥ 0`。合成完美排序必过、反向排序必拒（测试双侧）。成本若错：网格与边界可调，公式不放松。
9. **R-P7-9 — PSI 参考分布入工件**：训练时每特征写 `drift_reference`（lo/hi + 10 等宽箱占比 + missing_rate；nan 计缺失格）；`scripts/monitor_drift.py` 逐特征 PSI（越界并入端箱；零箱 epsilon=1e-6；缺失率差并入求和），任一 PSI > 0.2 → 报告 `alert:true` + exit 1。`app/observability.py` 增 `medintel_band_share`/`medintel_missing_rate` gauge 族（`/api/metrics` 现场聚合最近 ≤500 条分数）与 `medintel_drift_alerts_total` 计数。成本若错：参考随工件走（再训练即刷新），语义简单可审计。
10. **R-P7-10 — 再校准脚本门禁口径**：`scripts/recalibrate.py` 对输入标注集重算 margin → 拟合 isotonic → 写**临时工件** → `run_promotion_gate`（默认同一输入；`--gate-input` 可指独立留出集）→ 过则原子回写原工件（只动 `calibration`），不过 `exit 1` 原件分毫不动。同输入门禁的 in-sample 乐观性在 docstring 与报告注明（真实数据用独立留出集）。成本若错：demo 口径可接受，已披露。

def _serialize_trees(booster) -> list[dict]:
    """dump_model 拍平为 R-P7-3 节点列表；shrinkage=learning_rate。"""
    dump = booster.dump_model()
    shrinkage = float(dump.get("learning_rate", 1.0))
    trees: list[dict] = []
    for tree in dump["tree_info"]:
        nodes = []
        for node in tree["node_data"]:
            is_leaf = "leaf_value" in node
            nodes.append(
                {
                    "feature_order_index": int(node.get("split_feature", -1)),
                    "threshold": float(node.get("threshold", 0.0)),
                    "left": int(node.get("left_child", -1)),
                    "right": int(node.get("right_child", -1)),
                    "value": float(node.get("leaf_value", node.get("value", 0.0))),
                    "default_left": bool(node.get("default_left", True)),
                    "leaf": is_leaf,
                }
            )
        trees.append({"nodes": nodes, "shrinkage": shrinkage})
    return trees


def _drift_reference(matrix: list[list[float]], names: list[str]) -> dict:
    """每特征 lo/hi + 10 等宽箱占比 + 缺失率（Ruling R-P7-9）。"""
    reference: dict[str, dict] = {}
    for col, name in enumerate(names):
        values = [row[col] for row in matrix]
        finite = [v for v in values if v == v]
        lo, hi = (min(finite), max(finite)) if finite else (0.0, 1.0)
        if hi <= lo:
            hi = lo + 1.0
        width = (hi - lo) / 10
        counts = [0] * 10
        missing = 0
        for value in values:
            if value != value:
                missing += 1
            else:
                counts[min(int((value - lo) / width), 9)] += 1
        total = max(len(values), 1)
        reference[name] = {
            "lo": lo,
            "hi": hi,
            "proportions": [c / total for c in counts],
            "missing_rate": missing / total,
        }
    return reference
```

def _fit_lightgbm(
    times: list[dict],
    matrix: list[list[float]],
    labels: list[int],
    target_id: str,
    trials: int,
    seed: int,
):
    """Optuna 时间 CV：目标 = 平均 AUPRC − 0.1×ECE（WBS T7.1，Ruling R-P7-4）。"""
    import optuna
    from lightgbm import LGBMClassifier
    from scripts.evaluate_model import binary_metrics

    optuna.logging.set_verbosity(optuna.logging.WARNING)
    fold_rows = [
        {"index_time": t["index_time"], "_i": i, "label": str(labels[i])}
        for i, t in enumerate(times)
    ]
    folds = rolling_time_split(fold_rows, 3)
    x = np.asarray(matrix, dtype=float)
    y = np.asarray(labels, dtype=int)
    monotone = MONOTONE_CONSTRAINTS_BY_TARGET[target_id]

    def objective(trial: "optuna.Trial") -> float:
        params = {
            "n_estimators": trial.suggest_int("n_estimators", 50, 400),
            "learning_rate": trial.suggest_float("learning_rate", 0.02, 0.2, log=True),
            "num_leaves": trial.suggest_int("num_leaves", 7, 63),
            "min_child_samples": trial.suggest_int("min_child_samples", 5, 60),
            "subsample": trial.suggest_float("subsample", 0.6, 1.0),
            "colsample_bytree": trial.suggest_float("colsample_bytree", 0.6, 1.0),
            "reg_lambda": trial.suggest_float("reg_lambda", 1e-3, 10.0, log=True),
        }
        auprcs, eces = [], []
        for train_rows, test_rows in folds:
            train_idx = [r["_i"] for r in train_rows]
            test_idx = [r["_i"] for r in test_rows]
            if len({labels[i] for i in train_idx}) < 2:
                continue
            model = LGBMClassifier(
                objective="binary",
                monotone_constraints=monotone,
                deterministic=True,
                n_jobs=1,
                verbose=-1,
                **params,
            )
            model.fit(x[train_idx], y[train_idx])
            pred = model.predict_proba(x[test_idx])[:, 1]
            metrics = binary_metrics([labels[i] for i in test_idx], list(map(float, pred)), 0.5)
            auprcs.append(metrics["auprc"] or 0.0)
            eces.append(metrics["ece"] or 0.0)
        if not auprcs:
            return -1.0
        return sum(auprcs) / len(auprcs) - 0.1 * (sum(eces) / len(eces))

    sampler = optuna.samplers.TPESampler(seed=seed)
    study = optuna.create_study(direction="maximize", sampler=sampler)
    study.optimize(objective, n_trials=trials, show_progress_bar=False)
    best = LGBMClassifier(
        objective="binary",
        monotone_constraints=monotone,
        deterministic=True,
        n_jobs=1,
        verbose=-1,
        **study.best_params,
    )
    return best, study
```

```python
def _isotonic_apply(calibration: dict, z: float) -> float:
    """分段线性插值（端点 clip），纯 Python（Ruling R-P7-5）。"""
    xs = calibration["x_thresholds"]
    ys = calibration["y_scores"]
    if z <= xs[0]:
        return ys[0]
    if z >= xs[-1]:
        return ys[-1]
    for index in range(1, len(xs)):
        if z <= xs[index]:
            x0, x1 = xs[index - 1], xs[index]
            y0, y1 = ys[index - 1], ys[index]
            ratio = (z - x0) / (x1 - x0)
            return y0 + ratio * (y1 - y0)
    return ys[-1]
```

def subgroup_sensitivity_diff(
    labels: list[int],
    scores: list[float],
    groups: list[str],
    threshold: float,
    *,
    min_positives: int = 10,
) -> float | None:
    """两组灵敏度之差绝对值；任一组阳性不足或组数<2 → None（跳过，Ruling R-P7-6）。"""
    by_group: dict[str, tuple[int, int]] = {}
    for label, score, group in zip(labels, scores, groups):
        positives, detected = by_group.get(group, (0, 0))
        if label == 1:
            positives += 1
            if score >= threshold:
                detected += 1
        by_group[group] = (positives, detected)
    sensitivities = []
    for positives, detected in by_group.values():
        if positives < min_positives:
            return None
        sensitivities.append(detected / positives)
    if len(sensitivities) < 2:
        return None
    return abs(sensitivities[0] - sensitivities[1])


def per_facility_auprc(
    rows: list[dict],
    labels: list[int],
    scores: list[float],
    baseline_auprc: float,
    *,
    facility_column: str = "facility_id",
    min_rows: int = 20,
    min_positives: int = 5,
) -> dict:
    """按院区评估（Ruling R-P7-7）：合格院区 AUPRC ≥ baseline 才算过。"""
    from scripts.evaluate_model import binary_metrics

    buckets: dict[str, list[int]] = {}
    for index, row in enumerate(rows):
        facility = str(row.get(facility_column, "") or "")
        if not facility:
            return {"checked": False, "reason": f"missing {facility_column}", "failures": []}
        buckets.setdefault(facility, []).append(index)
    if len(buckets) < 2:
        return {"checked": False, "reason": "fewer than 2 facilities", "failures": []}
    failures = []
    worst = None
    for facility, indices in sorted(buckets.items()):
        if len(indices) < min_rows:
            continue
        facility_labels = [labels[i] for i in indices]
        if sum(facility_labels) < min_positives:
            continue
        auprc = (
            binary_metrics(facility_labels, [scores[i] for i in indices], 0.5)["auprc"] or 0.0
        )
        worst = auprc if worst is None else min(worst, auprc)
        if auprc < baseline_auprc:
            failures.append(
                {"facility": facility, "auprc": auprc, "baseline": baseline_auprc}
            )
    return {"checked": True, "worst": worst, "failures": failures}


def decision_curve_mean_gain(
    labels: list[int],
    scores: list[float],
    grid: list[float] | None = None,
) -> float:
    """mean(NB_model − max(NB_treat_all, 0))（Ruling R-P7-8）。"""
    if not labels or not sum(labels):
        raise ValueError("decision curve needs labels and at least one positive")
    thresholds = grid or [round(0.10 + 0.05 * i, 2) for i in range(17)]
    prevalence = sum(labels) / len(labels)
    gains = []
    for threshold in thresholds:
        tp = sum(
            1 for score, label in zip(scores, labels) if score >= threshold and label == 1
        )
        fp = sum(
            1 for score, label in zip(scores, labels) if score >= threshold and label == 0
        )
        nb_model = tp / len(labels) - (fp / len(labels)) * (threshold / (1 - threshold))
        nb_all = prevalence - (1 - prevalence) * (threshold / (1 - threshold))
        gains.append(nb_model - max(nb_all, 0.0))
    return sum(gains) / len(gains)

"""Batch drift monitoring against an artifact's stored reference (WBS T7.4)."""

import argparse
import csv
import json
import math
import sys
from pathlib import Path

# 直接以 `python scripts/x.py` 运行时根目录不在 sys.path（Ruling R14）。
if __package__ in (None, ""):
    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

PSI_THRESHOLD = 0.2  # WBS T7.4


def compute_psi(reference: dict, values: list, bins: int = 10) -> float:
    """PSI over reference bins（Ruling R-P7-9）；缺失并入独立格；epsilon 防零。"""
    lo, hi = float(reference["lo"]), float(reference["hi"])
    expected = list(reference["proportions"])
    width = (hi - lo) / bins if hi > lo else 1.0
    counts = [0.0] * bins
    missing = 0
    total = max(len(values), 1)
    for value in values:
        if value in ("", None):
            missing += 1
            continue
        try:
            numeric = float(value)
        except (TypeError, ValueError):
            missing += 1
            continue
        if not math.isfinite(numeric):
            missing += 1
            continue
        if numeric < lo:
            counts[0] += 1
        elif numeric > hi:
            counts[-1] += 1
        else:
            counts[min(int((numeric - lo) / width), bins - 1)] += 1
    actual = [c / total for c in counts]
    expected_missing = float(reference.get("missing_rate", 0.0))
    actual_missing = missing / total
    epsilon = 1e-6
    psi = 0.0
    for a, e in zip(actual, expected):
        psi += (a - e) * math.log((a + epsilon) / (e + epsilon))
    psi += (actual_missing - expected_missing) * math.log(
        (actual_missing + epsilon) / (expected_missing + epsilon)
    )
    return psi


def main() -> None:
    parser = argparse.ArgumentParser(description="PSI drift check against artifact reference")
    parser.add_argument("--artifact", required=True)
    parser.add_argument("--input", required=True, help="CSV batch to compare")
    args = parser.parse_args()
    artifact = json.loads(Path(args.artifact).read_text(encoding="utf-8"))
    reference = artifact.get("drift_reference")
    if not isinstance(reference, dict) or not reference:
        raise SystemExit(f"artifact has no drift_reference: {args.artifact}")
    with Path(args.input).open(newline="", encoding="utf-8-sig") as handle:
        rows = list(csv.DictReader(handle))
    if not rows:
        raise SystemExit("monitor_drift: empty input")
    report: dict = {"artifact": args.artifact, "rows": len(rows), "features": {}, "alert": False}
    for feature in artifact.get("feature_order", list(reference.keys())):
        if feature not in reference:
            continue
        column = [row.get(feature, "") for row in rows]
        psi = compute_psi(reference[feature], column)
        alert = psi > PSI_THRESHOLD
        report["features"][feature] = {"psi": psi, "alert": alert}
        report["alert"] = report["alert"] or alert
    print(json.dumps(report, ensure_ascii=False, indent=2))
    raise SystemExit(1 if report["alert"] else 0)


if __name__ == "__main__":
    main()
