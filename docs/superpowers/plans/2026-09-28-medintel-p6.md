## 写计划阶段的裁定（Plan Rulings）

1. **R1 — P6 特征空间 = 21 维（10 原始 + 10 `__missing` 指示 + news2_score），不用七元组 70 维**：serving 只有单事件 payload，无历史窗口无法复现 slope/mean 等；`evaluate_rows` 只读 `FEATURES`+news2；WBS P6 任务清单没有把 `build_landmarks` 接进 serving 的任何一步。"生成逻辑改为调 T5.1/T5.2 同构管道"裁定为**数据生成同源**（demo_patients→derive_labels 行），特征列以 serving 可复现为准。代价：七元组训练空间留待真实数据阶段（P8/P9）。
2. **R2 — 指示列训练端预计算、serving 端按名即时计算**：sklearn `add_indicator` 输出无名字无法进工件，改为训练矩阵显式加 `{feature}__missing` 列（命名与 T5.2 `STAT_SUFFIXES` 对齐）；`RiskEngine._score` preprocess 路径识别 `__missing` 后缀（基特征在 `FEATURES` 内时值 = payload 缺失?1.0:0.0，不走 median 填补），`missing_features` 仍只列真实缺失的基特征。效果等价 `add_indicator` 且工件自描述。
3. **R3 — 训练数据生成**：`build_demo_dataset(target_id, target_rows)`（train_model 内可导入函数）——`patients = max(18, ceil(target_rows/96))`，`demo_patients_with_outcomes(seed=7)` + `derive_labels` 取标签；`deterioration_24h` 用 1..96h 网格（阳性率≈5.6%）；`readmission_30d` 用"首事件+72h"为出院 index、`Random(42)` 抽 ~8% 患者在出院后 2–28 天造 `unplanned_readmission` 结局、`horizon_hours=720`；每行特征 = 该 index 前最新体征（`derive_labels._latest_payload_before`，scripts 内部复用）+ news2（baselines）+ 指示列；`--rows` 语义改为**目标行数**（默认 2500 → 27 患者 → 2592 行）。代价：CLI 旧行为（均匀随机行+latent 标签）被替换——该生成器正是 WBS 要求的"同构管道"。
4. **R4 — 时间三段切分**：按 `index_time` 排序 → 前 60% 训练 / 中 20% Platt 校准段 / 后 20% 验证段（thresholds 与评估用）。固定比例，时间有序，无泄漏。
5. **R5 — Platt 标定**：在训练段拟合的线性 logit 上，对校准段用 `LogisticRegression()` 拟合 `y ~ a*z + b`；工件 `calibration: {method: "platt", a, b}`；`_score` 在 `linear` 之后、`sigmoid` 之前统一应用（两条路径共用点），块为 `None/缺失` 跳过（旧工件兼容）。
6. **R6 — 阈值敏感度阶梯**（WBS 只给单参数，阶梯为本计划发明）：`thresholds.py --target-sensitivity S`（默认 0.90）→ `medium` = 满足 TPR≥S 的最高切点，`high` = TPR≥0.75S，`critical` = TPR≥0.5S；切点取自验证集实际分值集合、严格 `medium<high<critical`，撞相异分位时向更高分位步进，仍不可满足则 `ValueError` 响亮失败。
7. **R7 — promote 门禁契约**：`promote` 增加必填 `--input <labeled_csv>`；门禁 = bootstrap AUPRC CI 下界（`bootstrap_metric(n=1000, seed=20260928)`）≥ news2 AUPRC 点估计 且 `ece < 0.05`（ECE 10 箱等宽，作为**加性键**进 `binary_metrics` 输出）；不达标打印差距并 `SystemExit(1)`；报告写 `model-registry/<target_id>/<version>/eval.json`（比 WBS 字面多一层 target——与现有 registry 布局一致）。既有 `test_model_registry_promote_and_rollback` 补 `--input` 并改用能过门禁的工件/留出集（其覆盖的 promote/rollback 机制不变），更新入账。
8. **R8 — golden fixture 连工件一起提交**：`tests/fixtures/<target_id>/{golden_dataset.csv, model.json}` 双目标各一份——否则 fresh clone 无工件、drift 测试无法运行；`--check` 用数值容差 1e-9 比较（跨平台 BLAS 浮点），CI test job 每次执行（不只变更时——简单可靠）。
9. **R9 — `--rows` 为目标行数**（并入 R3 语义，见上）。
10. **R10 — `evaluate_rows` 注入 news2_score 列**：行含该列时加入 payload（与 `comparison_metrics` 的 enriched 路径对齐），使 golden 的 offline/serving 两路径在 news2 维度一致；无该列行为不变。既有 CLI 评估在含 news2 的 CSV 上分数会变（更正确），无测试断言旧值——T6.5 步骤内改。

"""Train the demo logistic model with scikit-learn (P6).

Data comes from the same synthetic pipeline the demo/import paths use
(P5 T5.1); serving stays dependency-free because the artifact carries
its own preprocess block (T5.3 v2).

import argparse
import contextlib
import json
import math
import sys
from datetime import datetime, timedelta
from pathlib import Path
from random import Random

# 直接以 `python scripts/x.py` 运行时根目录不在 sys.path（Ruling R14）。
if __package__ in (None, ""):
    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

import numpy as np
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

from app.synthetic import FEATURES, demo_patients_with_outcomes
from scripts.baselines import news2_score
from scripts.derive_labels import _latest_payload_before, derive_labels, demo_index_times
from scripts.validate import rolling_time_split

FEATURES_V2 = [
    *FEATURES,
    *[f"{feature}__missing" for feature in FEATURES],
    "news2_score",
]

TARGET_THRESHOLDS = {
    "deterioration_24h": {"medium": 0.2, "high": 0.45, "critical": 0.75},
    "readmission_30d": {"medium": 0.15, "high": 0.3, "critical": 0.55},
}
READMISSION_DISCHARGE_HOURS = 72
READMISSION_POSITIVE_RATE = 0.08


def _features_before(payload: dict) -> list[float]:
    base = [float(payload[f]) if payload.get(f) is not None else math.nan for f in FEATURES]
    indicators = [1.0 if math.isnan(value) else 0.0 for value in base]
    present = {k: v for k, v in payload.items() if v is not None}
    news2 = float(news2_score(present)[0]) if present else math.nan
    return [*base, *indicators, news2]


def build_demo_dataset(
    target_id: str, target_rows: int
) -> tuple[list[dict], list[list[float]], list[int]]:
    """T5.1 同源管道生成 (index_time 行, 21 维特征, 标签)（Plan Ruling R3/R9）。"""
    patients = max(18, math.ceil(target_rows / 96))
    _, events, outcomes = demo_patients_with_outcomes(count=patients, seed=7)
    if target_id == "deterioration_24h":
        index_times = demo_index_times(events)
        labeled = derive_labels(events, outcomes, index_times, horizon_hours=24)
    else:
        first_seen: dict[str, datetime] = {}
        for event in sorted(events, key=lambda item: item.occurred_at):
            first_seen.setdefault(event.encounter_id, event.occurred_at)
        index_times = {
            enc: at + timedelta(hours=READMISSION_DISCHARGE_HOURS)
            for enc, at in first_seen.items()
        }
        rng = Random(42)
        readmissions = [
            {
                "encounter_id": enc,
                "occurred_at": (at + timedelta(days=2 + rng.randrange(27))).isoformat(),
                "outcome_type": "unplanned_readmission",
            }
            for enc, at in first_seen.items()
            if rng.random() < READMISSION_POSITIVE_RATE
        ]
        labeled = derive_labels(events, readmissions, index_times, horizon_hours=720)
    events_by_encounter: dict[str, list[ClinicalEvent]] = {}
    for event in events:
        events_by_encounter.setdefault(event.encounter_id, []).append(event)
    rows: list[dict] = []
    matrix: list[list[float]] = []
    labels: list[int] = []
    for item in labeled:
        payload = _latest_payload_before(
            events_by_encounter.get(item.encounter_id, []), item.encounter_id, item.index_time
        )
        rows.append({"index_time": item.index_time.isoformat()})
        matrix.append(_features_before(payload))
        labels.append(item.label)
    return rows, matrix, labels


def _fit_pipeline(
    times: list[dict], matrix: list[list[float]], labels: list[int]
) -> tuple[Pipeline, float]:
    """C 网格 × rolling_time_split 时间交叉验证，按平均 AUPRC 选（WBS T6.1）。"""
    from scripts.evaluate_model import binary_metrics

    fold_rows = [
        {"index_time": t["index_time"], "_i": i, "label": str(labels[i])}
        for i, t in enumerate(times)
    ]
    folds = rolling_time_split(fold_rows, 3)

    def make_pipeline(c: float) -> Pipeline:
        return Pipeline(
            [
                # keep_empty_features：全空列不丢，保 21 维对齐（R2 关键）
                ("impute", SimpleImputer(strategy="median", keep_empty_features=True)),
                ("scale", StandardScaler()),
                (
                    "clf",
                    LogisticRegression(
                        C=c, penalty="l2", class_weight="balanced", max_iter=1000
                    ),
                ),
            ]
        )

    # C 选择的 CV 跑在全量行上（WBS 只要求"网格 × rolling_time_split 按 AUPRC 选"，
    # 未要求隔离验证段；最终模型仍只 fit train 60%——阈值段的行参与过选 C 属 demo 口径，接受）。
    c_grid = (0.01, 0.1, 1.0)
    best_c, best_score = c_grid[0], -1.0
    for c in c_grid:
        scores = []
        for train_rows, test_rows in folds:
            train_idx = [row["_i"] for row in train_rows]
            test_idx = [row["_i"] for row in test_rows]
            pipe = make_pipeline(c)
            pipe.fit(np.asarray(matrix, dtype=float)[train_idx], np.asarray(labels, dtype=int)[train_idx])
            pred = pipe.predict_proba(np.asarray(matrix, dtype=float)[test_idx])[:, 1]
            test_labels = [labels[i] for i in test_idx]
            value = binary_metrics(test_labels, list(map(float, pred)), 0.5)["auprc"]
            scores.append(value or 0.0)
        mean_auprc = sum(scores) / len(scores)
        if mean_auprc > best_score + 1e-12:
            best_c, best_score = c, mean_auprc
    return make_pipeline(best_c), best_c


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--output", default="data/model.json")
    parser.add_argument("--rows", type=int, default=2500, help="目标训练行数（Ruling R9）")
    parser.add_argument("--version", default="baseline-logistic-sklearn-v1")
    parser.add_argument(
        "--target-id",
        choices=["deterioration_24h", "readmission_30d"],
        default="deterioration_24h",
    )
    args = parser.parse_args()
    times, matrix, labels = build_demo_dataset(args.target_id, args.rows)

```python
"""Derive band cutpoints from a validation set (Plan Ruling R6)."""

import argparse
import csv
import json
import sys
from pathlib import Path

# 直接以 `python scripts/x.py` 运行时根目录不在 sys.path（Ruling R14）。
if __package__ in (None, ""):
    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from app.config import Settings
from app.risk import RiskEngine
from scripts.evaluate_model import evaluate_rows


def _max_threshold_at_tpr(scores: list[float], labels: list[int], tpr_target: float) -> float:
    positives = [s for s, y in zip(scores, labels) if y == 1]
    if not positives:
        raise ValueError("validation set has no positives; cannot derive thresholds")
    best = None
    for candidate in sorted(set(scores)):
        tpr = sum(1 for s in positives if s >= candidate) / len(positives)
        if tpr >= tpr_target - 1e-12:
            best = candidate
    if best is None:
        raise ValueError("threshold: no cutpoint satisfies the sensitivity target")
    return best


def derive_thresholds(
    scores: list[float], labels: list[int], target_sensitivity: float = 0.90
) -> dict[str, float]:
    """medium/high/critical = TPR ladder (S, 0.75S, 0.5S), strictly ascending (Ruling R6)."""
    ladder = (
        ("medium", target_sensitivity),
        ("high", target_sensitivity * 0.75),
        ("critical", target_sensitivity * 0.5),
    )
    result: dict[str, float] = {}
    previous = float("-inf")
    distinct = sorted(set(scores))
    for name, tpr in ladder:
        candidate = _max_threshold_at_tpr(scores, labels, tpr)
        while candidate <= previous:
            higher = [s for s in distinct if s > candidate]
            if not higher:
                raise ValueError(
                    "threshold: cannot form strictly ascending cutpoints from this score distribution"
                )
            candidate = higher[0]
        result[name] = candidate
        previous = candidate
    return result


def main() -> None:
    parser = argparse.ArgumentParser(description="Rewrite artifact thresholds from a holdout CSV")
    parser.add_argument("--artifact", required=True)
    parser.add_argument("--input", required=True)
    parser.add_argument("--label-column", default="label")
    parser.add_argument("--target-sensitivity", type=float, default=0.90)
    args = parser.parse_args()
    engine = RiskEngine(Settings(model_path=args.artifact, app_env="dev"))
    with Path(args.input).open(newline="", encoding="utf-8-sig") as handle:
        rows = list(csv.DictReader(handle))
    labels, scores = evaluate_rows(rows, engine, args.label_column)
    thresholds = derive_thresholds(scores, labels, args.target_sensitivity)
    artifact_path = Path(args.artifact)
    artifact = json.loads(artifact_path.read_text(encoding="utf-8"))
    artifact["thresholds"] = thresholds
    artifact_path.write_text(json.dumps(artifact, ensure_ascii=False, indent=2), encoding="utf-8")
    print(json.dumps({"artifact": str(artifact_path), "thresholds": thresholds}, ensure_ascii=False))


if __name__ == "__main__":
    main()
```

（**步进语义核对**：全同分值时 `distinct = [0.5]`，首个 candidate=0.5 > -inf 落座；第二个 candidate=0.5 ≤ previous → `higher` 空 → `ValueError("threshold...")` ✓ 与测试 match 一致。**敏感度方向核对**：TPR≥S 的最高切点——S 越小切点越高，故 medium(S) 最低、critical(0.5S) 最高，天然升序，步进仅在数据怪异时兜底。）

```python
def _expected_calibration_error(
    labels: list[int], scores: list[float], bins: int = 10
) -> float | None:
    if not labels:
        return None
    total = len(labels)
    buckets: list[list[tuple[int, float]]] = [[] for _ in range(bins)]
    for label, score in zip(labels, scores):
        buckets[min(int(score * bins), bins - 1)].append((label, score))
    ece = 0.0
    for bucket in buckets:
        if not bucket:
            continue
        confidence = sum(score for _, score in bucket) / len(bucket)
        accuracy = sum(label for label, _ in bucket) / len(bucket)
        ece += len(bucket) / total * abs(accuracy - confidence)
    return ece
```

"""Uncertainty sampling for human labeling (WBS T6.4).

只生成待标注清单——标签必须由人工填写，脚本绝不回写标签列。
"""

import argparse
import csv
import sys
from pathlib import Path

# 直接以 `python scripts/x.py` 运行时根目录不在 sys.path（Ruling R14）。
if __package__ in (None, ""):
    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from app.config import Settings
from app.domain import ClinicalEvent
from app.risk import RiskEngine
from app.synthetic import FEATURES


def _payload(row: dict) -> dict[str, float]:
    payload: dict[str, float] = {}
    for feature in FEATURES:
        raw = row.get(feature, "")
        if raw not in ("", None):
            payload[feature] = float(raw)
    if row.get("news2_score", "") not in ("", None):
        payload["news2_score"] = float(row["news2_score"])
    return payload


def select_for_labeling(rows: list[dict], engine: RiskEngine, top_n: int) -> list[dict]:
    """按 |p-0.5| 升序取 top-N；平局按 (encounter_id, index_time) 稳定排序。"""
    scored: list[dict] = []
    for index, row in enumerate(rows):
        event = ClinicalEvent(
            event_type="vital_signs",
            patient_id=str(row.get("patient_id", f"al-patient-{index}")),
            encounter_id=str(row.get("encounter_id", f"al-encounter-{index}")),
            payload=_payload(row),
        )
        probability = engine.score(event).score
        enriched = dict(row)
        enriched["score"] = probability
        enriched["uncertainty"] = abs(probability - 0.5)
        scored.append(enriched)
    scored.sort(
        key=lambda item: (
            item["uncertainty"],
            str(item.get("encounter_id", "")),
            str(item.get("index_time", "")),
        )
    )
    return scored[: max(top_n, 0)]


def main() -> None:
    parser = argparse.ArgumentParser(description="Rank unlabeled rows for human review")
    parser.add_argument("--input", required=True)
    parser.add_argument("--model", required=True)
    parser.add_argument("--target-id", default="deterioration_24h")
    parser.add_argument("--top", type=int, default=100)
    parser.add_argument("--output", required=True)
    args = parser.parse_args()
    engine = RiskEngine(Settings(model_path=args.model, app_env="dev"), target_id=args.target_id)
    with Path(args.input).open(newline="", encoding="utf-8-sig") as handle:
        reader = csv.DictReader(handle)
        rows = list(reader)
        fields = list(reader.fieldnames or [])
    picked = select_for_labeling(rows, engine, args.top)
    output = Path(args.output)
    output.parent.mkdir(parents=True, exist_ok=True)
    out_fields = [*fields, "score", "uncertainty"]
    with output.open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=out_fields)
        writer.writeheader()
        writer.writerows(picked)
    print(f"wrote {output} ({len(picked)} of {len(rows)} rows; labels remain human-owned)")


if __name__ == "__main__":
    main()
```

def _rows_equal(frozen: list[dict], fresh: list[dict]) -> str | None:
    if len(frozen) != len(fresh):
        return f"row count {len(frozen)} != {len(fresh)}"

            if (fa is None) != (fb is None):
                return f"row {i} {key}: {va!r} != {vb!r}"
            if fa is not None and abs(fa - fb) > TOLERANCE:
                return f"row {i} {key}: {va} != {vb}"
        for key in ("offline_score", "serving_score"):
            if abs(float(a[key]) - float(b[key])) > TOLERANCE:
                return f"row {i} {key}: {a[key]} != {b[key]}"
    return None


def main() -> None:
    parser = argparse.ArgumentParser(description="Freeze golden fixtures (or --check them)")
    parser.add_argument("--check", action="store_true", help="compare instead of write")
    args = parser.parse_args()
    drift: list[str] = []
    for target_id, artifact in DEFAULT_ARTIFACTS.items():
        if not artifact.exists():
            raise SystemExit(f"missing artifact {artifact}; train first")
        rows = build_fixture(target_id, artifact)
        fixture_dir = Path("tests/fixtures") / target_id
        csv_path = fixture_dir / "golden_dataset.csv"
        if args.check:
            if not csv_path.exists():
                drift.append(f"{target_id}: fixture missing")
                continue
            with csv_path.open(newline="", encoding="utf-8") as handle:
                frozen = list(csv.DictReader(handle))
            reason = _rows_equal(frozen, rows)
            if reason:
                drift.append(f"{target_id}: {reason}")
        else:
            fixture_dir.mkdir(parents=True, exist_ok=True)
            _write_csv(csv_path, rows)
            (fixture_dir / "model.json").write_text(
                json.dumps(
                    json.loads(artifact.read_text(encoding="utf-8")),
                    ensure_ascii=False,
                    indent=2,
                ),
                encoding="utf-8",
            )
            print(f"froze {len(rows)} rows -> {csv_path}")
    if drift:
        print("golden drift detected (run make_golden.py to regenerate):")
        for line in drift:
            print(f"  - {line}")
        raise SystemExit(1)
    if args.check:
        print("golden fixtures match")


if __name__ == "__main__":
    main()
```
