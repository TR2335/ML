## 写计划阶段的裁定（Plan Rulings）

1. **compose `APP_ENV` 保持 `dev` 默认**（主 WBS 字面写 `:-prod`）：prod → 强制 OIDC，而 compose 未配置 OIDC，`docker compose up` 快速启动会启动即崩。裁定：默认 dev + 端口绑定 `127.0.0.1` + 顶部醒目警告注释 + README 警告 + 应用级 fail-closed 校验（prod+demo 拒绝启动）。代价：有人不改环境把 compose 直接搬上生产会以 dev 模式运行，靠 localhost 绑定与文档警示兜底。
2. **`addopts` 直接移除 `--basetemp`**（主 WBS 写"改为相对临时路径"，当前值已是相对路径）：仓库内临时目录正是故障源（残留 `.pytest-tmp2/`、`.pytest_cache` 拒绝写入）。移除后 pytest 使用 OS 临时目录的每次运行唯一目录。代价：临时文件不再出现在仓库内，便于排查时需看 pytest 输出路径。
3. **BLE001 修法**：`/api/health` 的裸捕获下沉为 publisher 的"永不抛出"契约（`RedisStreamPublisher.health` 内 `except Exception  # noqa: BLE001` 附理由），api.py 删除 try/except。
4. **CSP 字面与实现**：字面 `default-src 'self'` 会封锁页面大量 inline `style=` 属性。裁定 header 为 `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; object-src 'none'; base-uri 'self'`——脚本侧严格执行（需外置 app.js + 事件委托），样式侧放行 inline（全面 class 化留待 P4/T4.1 一并做）。代价：style attribute 注入风险仍在，主要防线是 T1.4 的转义。
5. **`as_of` 存量回退字段用 `scored_at`**：主 WBS 写"缺失时视为 occurred_at"，但存量 `RiskScore` JSON 没有 `occurred_at` 字段，最接近的语义是 `scored_at`（写入时刻）。
6. **worker.py 无需修改**（主 WBS T1.2 列了 worker.py:47）：`as_of` 在 `RiskEngine.score()` 内部设置（`as_of=event.occurred_at`），sync API、redis worker、`rescore_once` 三条路径都经由 `engine.score()` 自动获得。
7. **`test_production_refuses_to_start_without_oidc` 需补 `demo_auth_enabled=False`**：新的 demo 检查排在 OIDC 检查之前，默认 `demo_auth_enabled=True` 会先命中 demo 错误。
8. **前端纯函数测试经 node 子进程执行**：`safe()` 是 JS，无法在 pytest 内直接运行。测试从 `app.js` 提取单行定义并用 `node -e` 执行断言；带 `skipif(node is None)` 环境守卫（注明理由），CI 增加 `setup-node` 保证始终执行。

        """Ping the broker; every client failure marks the bus unhealthy."""
        try:

                    event = ClinicalEvent.model_validate(json.loads(values["event"]))
