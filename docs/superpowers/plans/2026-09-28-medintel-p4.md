1. **目标分数回退必须真正移除**（T4.1）：目标 B 无分数时绝不得显示目标 A 的分数；fetch 失败必须有可见错误而非静默旧数据——`test_select_score_never_falls_back_to_other_target` + `test_show_does_not_use_generic_risk_fallback`。

4. **分页语义正确**（T4.4）：`X-Total-Count` 是 band 过滤后的总数而非切片长度；offset 越界返回空数组且总数不变；limit>1000 拒绝——`test_patient_pagination`。

## 写计划阶段的裁定（Plan Rulings）

1. **R1 — T4.3① 的"文档内容互换"已不存在**：实测 `head -1 docs/architecture.md` = `# 架构与演进`、`head -1 docs/data-contract.md` = `# 数据契约`，文件名与内容已对应（P5 的结局表型/工件 v2 追加落点正确）。T4.3 只做验收核对，不执行交换。代价：无（WBS 该项为过期描述）。
2. **R2 — 幂等比对按"显式提供"纳入 occurred_at**：pydantic `model_fields_set` 区分显式与默认（默认 `utc_now` 每次不同，直接纳入会让所有未带时间的重投递全部 409、打破既有幂等测试）。显式 provided → 全字段含 occurred_at 比对；未提供 → 维持 `exclude={"occurred_at"}`。代价：先自动后显式补时间的投递视为冲突（语义上是"不同事实"，可接受）。
3. **R3 — 分页在 API 层切片而非 SQL LIMIT/OFFSET**：`band` 过滤在 JSON、排序在 Python（两后端同构），SQL 层 LIMIT 会在过滤排序前截断，语义错误。修法改为：store 返回完整过滤排序列表 → API 计算 `total=len(rows)`、切 `rows[offset:offset+limit]`、回 `X-Total-Count`；SQL 级分页留待 band 列化（真实数据阶段）。WBS 字面"SQL 加 LIMIT/OFFSET"按正确性偏离。代价：O(n) 取全量（demo 规模可接受）。
4. **R4 — `MLFLOW_TRACKING_URI` 采"注明占位"而非删除**：P3 已按 R3 声明 `mlflow_tracking_uri` 字段，条目合法；`.env.example` 加注释说明用途。
5. **R5 — 非 dev 同时关闭 `/docs` 与 `/redoc`**：两者同为 schema 暴露面，WBS 只点 `docs_url`；一并 `None`（openapi.json 仍可显式访问的取舍不展开，记此裁定）。
6. **R6 — JWT leeway 测试带环境 skipif**：PyJWT 属 `[prod]` extra 本地未装（实测 `find_spec('jwt') is None`），测试以 skipif + 理由说明；代码改动（`leeway=30`）无条件生效。
7. **R7 — 集成测试默认排除**：`pyproject` 注册 `markers=["integration: ..."]` 且 `addopts` 追加 `-m "not integration"`（CLI `-m integration` 覆盖之）；compose postgres/redis 暴露 `127.0.0.1` 端口；测试内连不上服务即环境 skipif。
8. **R8 — event_backend 非法值统一文案**：API 已有 `raise ValueError(f"unsupported event backend: {settings.event_backend}")`（api.py:29）；worker 补同文案校验函数，测试断言两侧一致。
9. **R9 — health 降级原因码表**：`not found` → `model_artifact_missing`；`signature` → `model_signature_invalid`；其余 → `model_artifact_invalid`；原始原因（含路径）只经 `LOGGER` 输出。
10. **R10 — `selectScore` 纯函数置于 `app.js` 顶层**：`const selectScore = (p, target) => ...` 单行形式，node 测试按行正则提取执行（沿用既有 `safe()` 测试模式）。

"""Redis outage: publish fails → 503 + audit; retry after recovery is idempotent."""

import os
import socket
import subprocess
from datetime import UTC, datetime

import pytest

pytestmark = pytest.mark.integration


def _reachable(port: int, timeout: float = 1.0) -> bool:
    try:
        with socket.create_connection(("127.0.0.1", port), timeout=timeout):
            return True
    except OSError:
        return False


def _compose(*args: str) -> subprocess.CompletedProcess:
    return subprocess.run(
        ["docker", "compose", *args], capture_output=True, text=True, timeout=180
    )


@pytest.mark.skipif(
    os.environ.get("RUN_REDIS_FAILURE_TEST") != "1",
    reason="环境性守卫：会 stop/start redis 容器，仅 CI integration job（RUN_REDIS_FAILURE_TEST=1）或手动显式开启",
)
def test_publish_failure_returns_503_and_retry_recovers(tmp_path):
    if not _reachable(6379):
        pytest.skip("环境性守卫：Redis 未就绪")
    from fastapi.testclient import TestClient

    from app.config import Settings
    from app.main import create_app

    event = {
        "event_id": "evt-redis-1", "event_type": "lab_result", "patient_id": "pat-001",
        "encounter_id": "enc-001", "facility_id": "hospital-01",
        "occurred_at": datetime.now(UTC).isoformat(), "payload": {"lactate": 3.3},
    }
    headers = {"Authorization": "Bearer demo-clinician-token"}
    application = create_app(
        Settings(
            event_backend="redis",
            redis_url="redis://127.0.0.1:6379/0",
            model_path=str(tmp_path / "missing.json"),
        )
    )
    with TestClient(application) as client:
        healthy = client.post("/api/events", json=event, headers=headers)
        assert healthy.status_code == 202
        assert _compose("stop", "redis").returncode == 0
        try:
            down = client.post(
                "/api/events", json={**event, "event_id": "evt-redis-2"}, headers=headers
            )
            assert down.status_code == 503
            audit = client.get(
                "/api/audit", headers={"Authorization": "Bearer demo-quality-token"}
            )
            assert any(item["action"] == "event_publish_failed" for item in audit.json())
        finally:
            assert _compose("start", "redis").returncode == 0
        # 恢复后同 id 重试 → 幂等重发路径（入流成功）
        retry = client.post("/api/events", json=event, headers=headers)
        assert retry.status_code == 202
        # in-process 消费一轮，断言事件最终评分成功（幂等重发闭环）
        from app.risk import RiskEngine
        from app.storage import create_store
        from app.worker import consume_once
        from app.messaging import RedisStreamConsumer

        settings = Settings(
            event_backend="redis", redis_url="redis://127.0.0.1:6379/0",
            model_path=str(tmp_path / "missing.json"),
        )
        store = create_store(settings)
        engines = {
            "deterioration_24h": RiskEngine(settings),
            "readmission_30d": RiskEngine(settings, target_id="readmission_30d"),
        }
        consumer = RedisStreamConsumer(
            settings.redis_url, settings.redis_stream,
            group=settings.redis_consumer_group,
            consumer="it-consumer",
            dead_letter_stream=settings.redis_dead_letter_stream,
        )
        consume_once(store, engines, consumer, max_delivery_attempts=1)
        scores = store.get_scores("enc-001", "group-demo", "hospital-01")
        assert scores, "恢复后重试的事件最终被评分"
        store.close()
