# 模型卡：住院患者安全风险基线模型

## 目标

对成人普通住院患者进行两个独立目标的风险分层：未来 24 小时临床恶化（`deterioration_24h`）和出院后 30 天再入院（`readmission_30d`）。两个标签必须分别定义、分别训练和分别验证；当前工件使用合成数据，只用于平台联调，不能解释为已完成临床验证。

## 模型

可解释的逻辑回归，使用生命体征、实验室值、年龄和近期住院次数。两个目标有独立的模型版本、标签定义和风险阈值。训练脚本使用纯 Python 梯度下降，输出带版本的 JSON 模型工件。生产环境应使用经过审批的训练流水线和模型注册中心。

## 使用方式

模型分数用于患者排序、人工复核和资源分配。临床人员必须看到触发因素和数据时间，并可以确认、驳回或转入处置。模型不得单独用于诊断、用药、手术或出院决定。

## 验证要求

上线前必须报告 AUROC、AUPRC、灵敏度、特异度、校准曲线、决策曲线、缺失数据敏感性和按年龄、性别、院区、科室、设备与人群的亚组结果，并使用独立时间段和外部医院数据验证。
