## 写计划阶段的裁定（Plan Rulings）

1. **R1 — `MODEL_SIGNATURE_REQUIRED` 透传改空串语义**：compose 由 `${MODEL_SIGNATURE_REQUIRED:-false}` 改 `${MODEL_SIGNATURE_REQUIRED-}`（未设置时传空串），`Settings` 加 before-validator 把 `""` 归一为 `None`（pydantic 对 `bool | None` 不接受空串，已实测 `bool_parsing` 错误）。显式 `true`/`false` 仍可覆盖；这样 compose 演示栈（`APP_ENV` 默认 dev）行为不变，而只设 `APP_ENV=prod` 的部署自动获得 fail-closed。代价：与 WBS 字面"默认改 None"相比多了空串入口的归一化，属必要配套。
2. **R2 — OS 环境变量拼写错误无法用 `extra="forbid"` 拦截**：实测 pydantic-settings 2.15 对未知 OS 环境变量恒忽略（`extra=allow` 也不收录），`extra="forbid"` 只拦 `.env` 文件条目。因此 `test_prod_rejects_unknown_setting` 按 `.env` 条目路径写；OS 级拼写检查需要统一前缀（本项目 env 无前缀，`PATH/HOME` 等系统变量无法区分）——记为已知限制，不实现。代价：拼错 compose 传入的 OS 变量仍被静默忽略。
3. **R3 — 声明 `mlflow_tracking_uri` 字段保住 `.env.example` 兼容**：`.env.example` 含非 Settings 字段的 `MLFLOW_TRACKING_URI`，strict 模式会拒；在 `Settings` 显式声明该字段（`str = ""`，app 不消费，供外部工具读取）而非删示例行。代价：配置面多一个惰性字段。
4. **R4 — 审计旧行回填 `resource = facility 现值`**：历史行的资源归属不可考，按 WBS"默认回填现值"；幂等保护用"仅列缺失时迁移 + PG 侧 `WHERE resource_facility_id = ''` 守卫"，重复启动绝不覆盖。代价：迁移前 admin 写的旧行（facility `*`）回填后仍不可被院区过滤命中——历史数据尽力而为。

```python
def test_sync_loop_survives_rescore_failure(tmp_path, monkeypatch, caplog):
    import logging

    from app import worker
    from app.config import get_settings

    calls = {"n": 0}

    def flaky_rescore():
        calls["n"] += 1
        if calls["n"] == 1:
            raise RuntimeError("boom")
        raise KeyboardInterrupt  # 第二轮停止循环（BaseException，不被 except Exception 吞掉）

    monkeypatch.setattr(worker, "rescore_once", flaky_rescore)
    monkeypatch.setattr(worker, "HEARTBEAT_PATH", tmp_path / "heartbeat")
    sleeps: list[float] = []
    monkeypatch.setattr(worker.time, "sleep", lambda seconds: sleeps.append(seconds))
    with caplog.at_level(logging.ERROR, logger="app.worker"):
        with pytest.raises(KeyboardInterrupt):
            worker.run_sync_worker()
    assert calls["n"] == 2  # 失败后循环继续
    assert "sync rescore cycle failed" in caplog.text
    assert sleeps == [worker.sync_backoff_seconds(get_settings().score_interval_seconds, 1)]
    assert (tmp_path / "heartbeat").exists()
```

```python
    """Healthcheck signal: written every live cycle so a hang stops the updates."""
    try:
        HEARTBEAT_PATH.touch()
    except OSError:
        LOGGER.warning("failed to update worker heartbeat at %s", HEARTBEAT_PATH)


def sync_backoff_seconds(base_interval: int, consecutive_failures: int) -> float:
    """Fixed cadence after success; capped exponential backoff after failures."""
    if consecutive_failures <= 0:
        return float(max(base_interval, 1))
    return float(min(max(base_interval, 1) * 2**consecutive_failures, 3600))


def run_sync_worker() -> None:
    settings = get_settings()
    failures = 0
    while True:
        try:
            rescore_once()
            failures = 0
        except Exception:
            failures += 1
            LOGGER.exception("sync rescore cycle failed (%s consecutive)", failures)
        _touch_heartbeat()
        time.sleep(sync_backoff_seconds(settings.score_interval_seconds, failures))
```

```python
    def _migrate_audit_facility_scope(self) -> None:
        """Split legacy audit facility into actor/resource columns.

        Column adds are conditional; the backfill only touches rows the split
        never wrote, so repeated startups (or a crash between ALTER and
        UPDATE) can never overwrite explicit values (Plan Ruling R4).
        """
        columns = [
            row["name"]
            for row in self.connection.execute("PRAGMA table_info(audits)").fetchall()
        ]
        if not columns:
            return  # fresh database: CREATE TABLE includes the columns
        if "actor_facility_id" not in columns:
            self.connection.execute(
                "ALTER TABLE audits ADD COLUMN actor_facility_id TEXT NOT NULL DEFAULT ''"
            )
        if "resource_facility_id" not in columns:
            self.connection.execute(
                "ALTER TABLE audits ADD COLUMN resource_facility_id TEXT NOT NULL DEFAULT ''"
            )
        with self.connection:
            self.connection.execute(
                "UPDATE audits SET actor_facility_id = facility_id, "
                "resource_facility_id = facility_id "
                "WHERE actor_facility_id = '' OR resource_facility_id = ''"
            )
```
